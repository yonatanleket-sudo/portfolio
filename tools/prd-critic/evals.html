PRD-Critic Eval Methodology

Evaluation Methodology

How PRD-Critic's scores are checked against independent human judgment — published before the results exist, not after.

Pilot not yet run.

The protocol and label guide below are committed. Blind labeling of the golden set hasn't happened yet. This page will be updated with real per-dimension results once it has — it will never show placeholder or implied numbers in the meantime.

What this measures

PRD-Critic's per-dimension scores compared against independent, blind human labels on the same set of PRDs — not the critic's output judged by another LLM call using the same rubric. That design would be close to circular: a model grading its own instructions tends to agree with itself. This protocol exists specifically to avoid that.

This is a pilot, not a benchmark: about 18 PRDs, one labeler, no adjudication pass. It will report exactly what it finds and nothing more.

What is not claimed

  • No single headline "alignment rate" or accuracy percentage
  • No claim that results generalize beyond the labeled golden set
  • No inter-rater reliability claim — there is one rater; a second labeler and adjudication is future work, not promised on a timeline
  • No claim that the rubric itself is objectively correct — it's one experienced PM's judgment, made explicit and checkable rather than left implicit

All 18 are original and fictionalized — invented companies, invented features, invented numbers — spanning data/ML features, workflow-automation features, and pure-UI features (6 each), and deliberately spanning quality levels so scores aren't compressed at one end. None describe or derive from any real employer's product or data. Full set: tools/prd-critic/golden-set.json.

This set is kept separate from the canned-demo PRD shown on the tool page — that critique is already public, so it can't be used for blind labeling without contaminating the result.

Label guide

For each dimension, scored 1–5 independently, without seeing the critic's output for that PRD:

ScoreMeaningAnchor
1Missing / unusableNot addressed, or too vague to act on
2Seriously underspecifiedGestured at, missing the specifics needed to build or evaluate against it
3AdequateEnough to proceed; gaps a reviewer would flag but not block on
4ClearSpecific, falsifiable, actionable with only minor gaps
5CompleteNothing an experienced reviewer would add

Blinding procedure

  1. Labels are recorded before the critic is run against that PRD.
  2. Labeling happens in one sitting where practical, to reduce drift in how anchors are applied across the set.
  3. The critic then runs once per PRD — no re-rolling for a more favorable output — and scores are compared.

Reporting (once labeling is complete)

For each of the 6 dimensions, across the full set:

  • Exact agreement rate (critic score equals label)
  • Within-1 agreement rate (scores differ by at most 1 point)
  • Mean signed difference — reveals systematic leniency or harshness per dimension
  • 2–3 concrete disagreement examples per dimension, with both scores and enough PRD context to see why they diverged

Future work

Noted for honesty, not promised on a timeline: a second independent labeler with an adjudication pass on disagreements (to get an actual inter-rater number instead of one person's judgment), expanding the set past 18–20, and a same-labeler re-label after a time gap to estimate how much disagreement is labeler noise versus real critic error.
